              New Refinement Package

              Cuts every particle in a particle position group out of its image into a stack, with the image's CTF estimate carried along, and starts the package with a “Random Parameters” refinement — cisTEM’s New Refinement Package wizard.

              Export Refinement Package

              Writes one refinement’s parameters for one class beside a copy of the package’s particle stack, on the machine running the API server — cisTEM’s Export Refinement Package wizard.

              Relion stacks are written white-on-black and normalised outside the particle radius, as the wizard does; Frealign and cisTEM exports copy the stack as it is. An existing file at either path is overwritten.

              Import Refinement Package

              A particle stack and its parameter file, on the machine running the API server, become a refinement package with an “Imported Parameters” refinement — cisTEM’s Import Refinement Package wizard. The stack is used where it is, not copied; its particles have no parent image in this project.

              Import Particle Positions

              A text file with one position per line: the image asset I.D. (or the image's filename), then X and Y in Ångstroms. Lines starting with # are skipped. Imported positions carry no pick job and join All Particle Positions.

              Import Volumes

              MRC volumes from outside the project — a starting reference, a mask — at one pixel size. Reconstructions made here arrive on their own.

              Import Images

              For micrographs that were already averaged elsewhere — images produced by Align Movies in this project arrive on their own.
